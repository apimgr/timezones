Quick Examples

Get all timezones
curl http://localhost:8080/api/v1/timezones
Search for "pacific"
curl http://localhost:8080/api/v1/timezones/search?q=pacific
Get timezones with offset -5 (EST)
curl http://localhost:8080/api/v1/timezones/offset/-5
Get timezone for America/New_York
curl http://localhost:8080/api/v1/timezones/utc/America/New_York

Data Format

Each timezone entry contains:

  • value - Timezone name (e.g., "Eastern Standard Time")
  • abbr - Abbreviation (e.g., "EST", "PST")
  • offset - UTC offset in hours (e.g., -5, 0, +8)
  • isdst - Whether DST is active (boolean)
  • text - Human-readable description
  • utc - Array of IANA timezone identifiers
